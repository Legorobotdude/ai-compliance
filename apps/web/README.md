# Web Application

Next.js + React admin dashboard for compliance ops. Talks to the API via tenant-scoped JWTs and renders the Explorer, Supplier Scorecards, Impact Simulator, Ops Center, and LLM log viewers.

## Responsibilities
- Implement route groups for dashboards and detail views.
- Provide shared UI components (tables, charts, virtual lists) aligned with Tailwind design tokens.
- Integrate with CORA previews (email drafts, risk summaries).
- Handle client-side telemetry and feature flags per tenant role.
