# Supplier Module

Manages supplier master data, scorecards, request workflows, and CORA-powered outreach.

- Models for `suppliers`, `component_suppliers`, `supplier_requests`, SLAs.
- Request lifecycle + reminder scheduling, integrating with Temporal activities.
- KPIs for scorecards plus Ops Center “slow responder” feeds.
- CORA adapters for multi-language outreach and response ingestion webhooks.
